# 📅 Calendar and Reminder App

A simple desktop **Calendar and Reminder Application** built using Python and Tkinter.  
The application allows users to view a monthly calendar and manage reminders through a user-friendly graphical interface.

## ✨ Features

- 📅 Display a monthly calendar
- 🗓️ Select month and year
- 🔔 Add and set reminders
- 📋 View saved reminders
- 🗑️ Delete/manage reminders
- 🖥️ Simple and user-friendly GUI
- 💾 Store reminders for future access

## 🛠️ Technologies Used

- **Python 3**
- **Tkinter**
- **Calendar module**
- **Datetime module**
